# Cafetería Aroma

Proyecto escolar para la práctica de control de versiones de Programación Web Integral.

## Estructura del proyecto

- `index.html`: contiene la estructura y el contenido de la página.
- `css/estilos.css`: contiene los estilos visuales y el diseño adaptable.
- `img/`: carpeta destinada a guardar imágenes del sitio.

## Cómo abrir el sitio

1. Descarga o clona este repositorio.
2. Abre la carpeta `cafeteria-web`.
3. Abre el archivo `index.html` en un navegador.

## Personalización

Los datos de teléfono y ubicación que aparecen en la página son ejemplos. Cámbialos por los datos que indique el docente o por información ficticia claramente identificada.
